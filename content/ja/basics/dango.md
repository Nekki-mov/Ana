# Dango と Mochi

ソフトウェアのインストールって、本当はもっとシンプルであるべきです。

Wagashi Linux では、その中心にあるのが dango というツール。

…とはいえ、たぶんあなたはそこまで意識することはないはずです。

---

## じゃあ… dango って何？

dango は、Wagashi Linux がソフトウェアを探したり、インストールしたり、更新したり、削除したりするための仕組みです。

内部では Arch Linux の公式リポジトリや AUR と連携しています。

でも、一番大事なのはここです。

そういう細かいことは、気にしなくて大丈夫。

面倒な部分は dango が全部やってくれます。

実は、アプリケーションのセクションを読んでいたなら…もうすでに使っていたりします。

気づいていなかっただけで。

---

## Mochi — ここが本番です

正直に言いましょう。

ほとんどの人は、ターミナルでコマンドを打ちながらアプリをインストールしたくありません。

だからこそ Mochi があります。

Mochi は dango のグラフィカルインターフェースです。

つまり――

同じことをするけれど、変なコマンドを覚える必要はありません。

メニューから Mochi を開くと、こんなものがあります。

* カテゴリー — 音楽、ゲーム、写真、開発など、用途ごとに整理されたアプリ
* 検索 — 欲しいものを入力すれば、自動で探してくれます
* インストール済み — 今システムに入っているもの一覧
* アップデート — 新しいバージョンをワンクリックで更新

何か見つける。

インストールを押す。

少し待つ。

終わり。

それだけです。

---

## どうして二つあるの？

役割が違うからです。

dango はエンジン。

Mochi はあなたが実際に使うもの。

普段はほとんど Mochi を使うことになるでしょう。

でも、ターミナルが好きなら dango もいつでも使えます。

```
dango -S firefox       # インストール
dango -R firefox       # 削除
dango -Syu             # 全部更新
dango -Ss firefox      # 検索
```

やり方は違います。

でも結果は同じ。

好きな方を使ってください。

---

## ちなみに…

もしかすると、もう気づいたかもしれません。

dango と Mochi は、どちらも日本のお菓子の名前です。

もちろん、適当に決めたわけではありません。

Wagashi Linux では、名前にも少し遊び心を入れています。

そして今回は――

この二つ、なかなかいい組み合わせなんです。
