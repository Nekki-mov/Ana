# ファイルとフォルダ

パソコンの中にあるものは、ほとんど全部ファイルとフォルダで整理されています。

…まあ、それくらいはもう知っていますよね。

ここで話したいのはそこではありません。

もっと実用的な話です。

自分のファイルがどこにあるのか。

そして――

あとで「あれどこだっけ？」とならないための話です。

---

## ファイルはどこにあるの？

あなた専用のフォルダは **ホームフォルダ** と呼ばれます。

Wagashi Linux では、だいたいこんな感じです。

```
/home/your_username
```

Windows を使ったことがあるなら、ユーザーフォルダみたいなものだと思ってください。

あなたが使うファイルのほとんどは、ここにあります。

中にはこんなフォルダがあります。

* Documents — 仕事用のファイルや PDF など
* Downloads — ダウンロードしたものが最初に入る場所
* Pictures — 写真やスクリーンショット
* Music と Videos — 名前そのままです

インストールした時点で、これらはすでに用意されています。

自分で作る必要はありません。

もし迷ったら――

とりあえずホームに戻れば大丈夫です。

---

## パスって何？

ファイルにもフォルダにも、それぞれ「住所」があります。

それを **パス** と呼びます。

例えば――

```
/home/nekane/Documents/report.pdf
```

左から順番に見ていきます。

最初はシステムの一番上 (`/`) 。

その次に `home` 。

その次にあなたのユーザー名。

その次にフォルダ。

最後にファイルそのものです。

普段はこういうものを手で入力することはほとんどありません。

普通にフォルダをクリックしていけば同じことです。

でも覚えておくと便利です。

チュートリアルでこう言われることがあります。

*「このパスに移動してください」*

そういう時に助かります。

ちなみに――

ファイルを右クリックすると、パスをコピーできることもあります。

かなり便利です。

覚えておいて損はありません。

---

## 隠しファイル

一部のファイルやフォルダは、最初から隠されています。

例えばこんな感じです。

```
.config
.bashrc
```

こういうものは、設定ファイルであることが多いです。

だから普段は見えないようになっています。

もし表示したいなら、多くの場合はこれです。

**Ctrl + H**

これで表示したり隠したりできます。

でも――

ここはちょっとだけ注意。

何のファイルかわからないなら…

まだ消さない方がいいです。

中にはかなり大事なものもあります。

本当に。

---

## 移動したりコピーしたり

いくつか覚えておくと便利なことがあります。

* コピー は複製を作ります
* 切り取り は別の場所へ移動します
* 普通にドラッグすると移動
* Ctrl を押しながらドラッグするとコピーになることが多いです
* F2 で名前変更
* ゴミ箱は空にするまで完全削除ではありません

それと、一つだけアドバイス。

Downloads フォルダをブラックホールにしないでください。

大事なものをダウンロードしたなら――

ちゃんと別の場所へ移しましょう。

未来の自分が感謝します。

かなり。

---

## エディションによって少し変わります

Wagashi Linux では、エディションによってファイルマネージャーが違います。

でも安心してください。

考え方は全部同じです。

違うのは見た目だけ。

### Dolphin (Ayu, Sayuri)

Dolphin には便利な機能がいくつかあります。

* F3 — 画面を二つに分割
* Ctrl + T — 新しいタブ
* プロパティ からサイズや権限を確認
* プレビュー機能が使える場合があります
* 上のバーから直接パス入力
* Shift + Delete で完全削除

最後のやつは――

気をつけてください。

### PCManFM (Mishio, Nayuki)

PCManFM はもっと軽くてシンプルです。

でも、それは悪いことではありません。

余計なものが少ないだけです。

そのぶん速いです。

* Ctrl + L — パス入力
* Ctrl + T — 新しいタブ
* 右クリックで基本操作
* 古いハードウェアでは、この軽さがかなり役立ちます

機能は少なめ。

でも速い。

それで十分です。

---

## 最後にひとつだけ

今日これを全部覚える必要はありません。

本当に。

大事なのは、全部暗記することではありません。

まずは自分のシステムがどう整理されているか知ることです。

ファイルマネージャーを開いてみてください。

少し触ってみる。

Downloads を見てみる。

フォルダを移動してみる。

いろいろ押してみる。

気になったものを触ってみる。

残りは――

使っていれば自然と覚えます。
