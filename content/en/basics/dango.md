# Dango and Mochi

Installing software should be simple.

On Wagashi Linux, everything revolves around a tool called dango.

And honestly… you probably won't need to think much about it.

---

## So… what exactly is dango?

dango is the system Wagashi Linux uses to find, install, update, and remove software.

Behind the scenes, it connects to Arch's official repositories and the AUR.

But here's the important part:

you don't need to worry about any of that.

dango handles all the complicated stuff for you.

In fact, if you already checked the Applications section, you've technically used it already… even if you didn't know its name.

---

## Mochi — where the magic happens

Let's be honest.

Most people don't want to install software by typing commands into a terminal.

That's exactly why Mochi exists.

Mochi is dango's graphical interface.

In other words:

It does exactly the same thing… without asking you to type weird commands.

Open Mochi from the menu and you'll find:

* Categories — apps organized by what you need: music, games, photography, development, and more.
* Search — type what you're looking for and dango will search everywhere automatically.
* Installed — everything currently installed on your system.
* Updates — new versions ready to install with a single click.

Find something.

Click install.

Wait a few seconds.

Done.

That's it.

---

## Why are there two of them?

Because they each have a different role.

dango is the engine.

Mochi is what you interact with.

Most of the time, you'll be using Mochi for pretty much everything.

But if you like working in the terminal, dango is always there too:

```
dango -S firefox       # install something
dango -R firefox       # remove something
dango -Syu             # update everything
dango -Ss firefox      # search for something
```

Two different ways.

Exactly the same result.

Use whichever feels better to you.
