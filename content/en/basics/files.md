# Files and folders

Your computer organizes almost everything into files and folders.

You probably knew that already.

We're not going to start by explaining what a folder is.

This is about something more useful:

understanding where your stuff actually lives…

and not losing track of it along the way.

---

## Where your files live

Your personal folder is called your **home folder**.

On Wagashi Linux, it usually looks like this:

```
/home/your_username
```

If you're coming from Windows, think of it as your user folder.

It's where pretty much everything that belongs to you lives inside the system.

Inside, you'll usually find folders like:

* Documents — work files, PDFs, text files, projects
* Downloads — anything you download from the internet lands here first
* Pictures — photos, screenshots, images in general
* Music and Videos — pretty self-explanatory

These folders already exist when you install the system.

You don't need to create anything.

And if you ever feel lost…

going back to your home folder is usually a good place to start.

---

## Paths — how to find any file

Every file and folder has an address.

That's called a **path**.

For example:

```
/home/nekane/Documents/report.pdf
```

Read it from left to right.

First comes the root of the system (`/`).

Then `home`.

Then your username.

Then the folder.

And finally, the file itself.

Most of the time, you won't need to type paths manually.

Clicking through folders does exactly the same thing.

But understanding paths becomes incredibly useful when a tutorial says something like:

*"go to this path"*

or when you need to find something manually.

Small useful trick:

most file managers let you copy a file's full path by right-clicking it.

Trust me.

You'll use that eventually.

## Hidden files

Some files and folders are hidden by default.

Their names usually begin with a dot, like:

```
.config
.bashrc
```

These usually contain system or application configuration.

That's why they stay hidden most of the time.

If you ever need to see them, most file managers let you use:

**Ctrl + H**

That will show or hide hidden files instantly.

But here's something important.

If you don't know exactly what a hidden file does…

you probably shouldn't delete it just yet.

Some of them contain important things.

Very important things.

---

## Moving, copying… and not losing things

There are a few simple habits that can save you a lot of frustration.

* Copy creates a second copy of a file
* Cut moves a file somewhere else and removes it from the original location after pasting
* Dragging a file normally moves it
* Dragging while holding Ctrl usually creates a copy instead
* You can rename files by pressing F2 or simply clicking on the filename
* The Trash does not permanently delete files until you empty it

And one important tip.

Don't turn your Downloads folder into a black hole.

If you download something important…

move it somewhere else.

Your future self will appreciate that.

A lot.

## Now this depends on which edition you're using

Wagashi Linux ships with different file managers depending on the edition.

Everything above works exactly the same everywhere.

Only the interface changes.

### Dolphin (Ayu, Sayuri)

Dolphin is KDE's file manager, and it has a few very useful tricks.

* F3 splits the window into two panels, perfect for moving files between folders quickly
* Ctrl + T opens a new tab
* Right-clicking and opening Properties lets you check file size, type, and permissions
* If previews are enabled, many files can be previewed instantly
* You can manually type paths directly in the top address bar
* Shift + Delete permanently deletes a file without sending it to the Trash

That last one…

use it carefully.

### PCManFM (Mishio, Nayuki)

PCManFM is lighter and simpler by design.

And no, that doesn't mean it's worse.

It simply does fewer things.

But it does them fast.

* Ctrl + L lets you manually type paths
* Ctrl + T opens a new tab
* The right-click menu gives you all the essentials: open, copy, move, delete, properties
* On older hardware, speed often matters more than extra features

Fewer options.

Less distraction.

More speed.

## One last thing

You do not need to memorize all of this today.

Seriously.

The important part isn't learning every keyboard shortcut or remembering every folder.

The important part is starting to understand how your system organizes itself.

Open your file manager.

Explore a little.

Look inside your Downloads folder.

Move between folders.

Click on things.

Be curious.

The rest…

you'll learn naturally along the way.
